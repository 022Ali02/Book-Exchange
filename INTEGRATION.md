# BookSwap - Интеграция завершена

## Что реализовано

### ✅ API Клиент и Сервисы
- `src/services/api.ts` - Axios instance с автоматическим добавлением токена
- `src/services/authService.ts` - Регистрация, вход, профиль
- `src/services/bookService.ts` - CRUD операции с книгами
- `src/services/exchangeService.ts` - Управление обменами
- `src/services/messageService.ts` - Отправка и получение сообщений
- `src/services/recommendationService.ts` - AI рекомендации и wishlist

### ✅ Аутентификация
- `src/contexts/AuthContext.tsx` - Context API для управления пользователем
- `src/app/components/PrivateRoute.tsx` - Защита приватных роутов
- Автоматическая загрузка профиля при наличии токена
- Сохранение токена в localStorage
- Редирект на /login при 401 ошибке

### ✅ Обновленные страницы
- **Login** - Подключен к API, обработка ошибок, редирект после входа
- **Register** - Валидация паролей, автоматический вход после регистрации
- **Catalog** - Загрузка книг из API, фильтры, поиск, пагинация
- **Profile** - Загрузка своих книг, wishlist, истории обменов
- **BookDetail** - Загрузка деталей книги, предложение обмена, добавление в wishlist
- **AIMatch** - AI рекомендации с возможностью добавить в wishlist
- **Exchange** - Список обменов, чат, подтверждение/отклонение

### ✅ Новые компоненты
- **AddBookModal** - Модальное окно для добавления книги с полной формой
- **ExchangeModal** - Модальное окно для выбора своей книги и создания обмена
- **Layout** - Обновлен для отображения статуса аутентификации

### ✅ Функционал
- Регистрация и вход пользователей
- Добавление книг на обмен
- Просмотр каталога с фильтрами
- AI рекомендации на основе предпочтений
- Создание предложений обмена
- Чат между участниками обмена
- Подтверждение/отклонение обменов
- Wishlist (список желаний)
- История завершенных обменов
- Toast уведомления для всех действий

## Как запустить

### Бэкенд
```bash
cd backend
npm install
# Создайте .env файл с настройками PostgreSQL
npm run seed  # Заполнить тестовыми данными (опционально)
npm run dev   # Запуск на http://localhost:5000
```

### Фронтенд
```bash
npm install
npm run dev   # Запуск на http://localhost:5173
```

## Тестирование

1. **Регистрация нового пользователя:**
   - Откройте http://localhost:5173/register
   - Заполните форму
   - После регистрации вы автоматически войдете

2. **Добавление книги:**
   - Перейдите в Профиль
   - Нажмите "Добавить книгу"
   - Заполните форму и сохраните

3. **Просмотр каталога:**
   - Перейдите в Каталог
   - Используйте фильтры и поиск
   - Откройте детали книги

4. **Предложение обмена:**
   - На странице книги нажмите "Предложить обмен"
   - Выберите свою книгу
   - Отправьте предложение

5. **Обработка обменов:**
   - Перейдите в "Обмены"
   - Просмотрите входящие/исходящие
   - Отправьте сообщение
   - Подтвердите или отклоните обмен

6. **AI рекомендации:**
   - Перейдите в "AI-подбор"
   - Просмотрите персонализированные рекомендации
   - Добавьте книги в wishlist

## API Endpoints

Все endpoints доступны на `http://localhost:5000/api`:

- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход
- `GET /auth/profile` - Получить профиль
- `GET /books` - Список книг (с фильтрами)
- `POST /books` - Создать книгу
- `GET /books/my-books` - Мои книги
- `POST /exchanges` - Создать обмен
- `GET /exchanges` - Мои обмены
- `PUT /exchanges/:id/status` - Обновить статус
- `POST /messages` - Отправить сообщение
- `GET /messages/exchange/:id` - Получить сообщения
- `GET /recommendations/ai-match` - AI рекомендации
- `POST /recommendations/wishlist` - Добавить в wishlist
